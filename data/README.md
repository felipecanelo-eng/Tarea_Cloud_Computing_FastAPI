# Dataset

## Sleep Debt and Screen Time — Late Night Phone Habits

This project uses the public Kaggle dataset:

**Sleep Debt and Screen Time — Late Night Phone Habits**

Source:

https://www.kaggle.com/datasets/samartalwar/sleep-debt-and-screen-time-late-night-phone-habits

## Dataset characteristics

The dataset used in this project contains:

- 8,500 observations
- 18 original columns
- Numerical and categorical variables
- Multiclass target: `sleep_debt_category`

The target contains four classes:

- Mild Deficit
- Moderate Debt
- Optimal Recovery
- Severe Sleep Debt

## How to obtain the dataset

data/bedtime_screentime_sleep_debt.csv
